Deux architectures pour le même LLM

Volet avancé du sujet : appel direct des outils contre planification en étapes.

A · Appel direct

  • • Souple : choisit l'outil au fil de l'eau
  • • Moins d'appels au modèle, plus rapide
  • • Défaut : questions inutiles (7 tours ratés)
  • • Un document lu peut orienter la suite

B · Plan puis exécution

  • • Oblige à prévoir toutes les étapes
  • • Un outil par étape : moins de confusion
  • • Défaut : mauvais outil si le plan est faux
  • • Sécurité : rien d'imprévu après lecture

Lien avec le cours

  • • Modèle de langue : prédit le prochain token
  • • Le JSON du plan est un texte généré
  • • Décodage glouton (τ = 0) : reproductible
  • • Contrainte de sortie = contrôle de la génération
