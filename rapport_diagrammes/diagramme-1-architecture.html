Architecture du système : de la phrase à l'action contrôlée

Chaque tour : le texte est analysé (TALN), un décideur choisit un outil, la défense filtre, le correcteur note tout depuis le journal.

Briques TALN (cours ch. 1–2)

  • • Normalisation : minuscules, suppression des accents
  • • TF-IDF mots + n-grammes de caractères (fautes, OOV)
  • • Classification d'intention : F1 macro TEST = 0,982
  • • Entités par expressions régulières + distance d'édition

Décideur : ce qu'on compare

  • • Baseline règles : 65,0 % des tâches
  • • Agent classique : 98,3 %
  • • Qwen2.5-3B direct : 68,3 % · plan : 83,3 %
  • • Même correcteur, mêmes 60 scénarios TEST

Contrôle et confiance

  • • Garde : « le modèle propose, le système impose »
  • • Attaques réussies : 33 % sans défense → 0 % avec
  • • Audit humain : kappa 0,25 (accord passable)
  • • Le correcteur est plus sévère que l'humain
